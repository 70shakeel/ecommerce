# Nike Clone E-commerce

A modern, high-performance e-commerce application built with Next.js 16, imitating the Nike website experience. This project showcases a premium design with smooth animations and robust functionality.

## Features

- **Modern Tech Stack**: Built with Next.js 16 (App Router), React 19, and TypeScript.
- **Styling**: Tailwind CSS 4 for utility-first styling, with Framer Motion for animations.
- **UI Components**: Utilizes Radix UI primitives and Lucide React icons.
- **Authentication**: (In Progress) Member registration and login functionality.
- **Product Features**:
    - Product browsing.
    - Wishlist functionality.
    - Membership integration.
- **Backend Integration**: Setup for Supabase and Stripe (dependencies included).

## Getting Started

First, install the dependencies:

```bash
npm install
# or
yarn install
# or
pnpm install
# or
bun install
```

Then, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Project Structure

- `app/`: Next.js App Router pages and layouts.
- `components/`: Reusable UI components.
- `lib/`: Utility functions and library configurations.
- `public/`: Static assets.
